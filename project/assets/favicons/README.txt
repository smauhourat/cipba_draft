imgtoolsbase favicon ZIP

Includes: favicon.ico (16/32/48 px) and PNGs at 16, 32, 48, 64, 128, 180, 192, 512 px.
This is a practical starter pack; it does not include site.webmanifest, maskable icons, a Safari pinned-tab SVG, or browserconfig.xml.

Usage in HTML:
  <link rel="icon" href="/favicon.ico">
  <link rel="icon" type="image/png" sizes="32x32" href="/favicon-32x32.png">
  <link rel="apple-touch-icon" sizes="180x180" href="/favicon-180x180.png">
